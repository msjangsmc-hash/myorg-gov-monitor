체크포인트: 운영 중인 Citrix NetScaler ADC 및 Gateway 등 인프라의 버전 영향도를 파악하여 최신 보안 패치를 즉시 적용하십시오.

[KISA 보호나라] - Adobe 제품 보안 업데이트 권고
체크포인트: 사내 엔드포인트에 설치된 Adobe Acrobat 및 Reader 등 클라이언트 소프트웨어를 중앙 관리 도구(EMS)로 최신 업데이트하십시오.

[KISA 보호나라] - CVE-2026-24498 | EFM-Networks ipTIME 유무선공유기 제품군 보안 기능 우회
체크포인트: 원격근무 및 지사/사업장에 설치된 ipTIME 공유기 펌웨어를 최신 버전으로 업데이트하고 원격 관리 포트(WAN 접속)를 비활성화하십시오.

[KISA 보호나라] - CVE-2026-24497 | 심테크시스템 Thinkwise 버퍼오버플로우
체크포인트: Thinkwise 소프트웨어 사용 현황을 파악하고 임의 코드 실행 공격을 방어하기 위해 제조사 최신 패치를 일괄 적용하십시오.

[KISA 보호나라] - CVE-2025-29867 | 한글과컴퓨터 한컴오피스 Type Confusion 취약점
체크포인트: 전사 한컴오피스 자동 업데이트 상태를 확인하고 악성 HWP/HWPX 첨부파일 실행에 대비한 EDR 탐지 룰을 강화하십시오.

[KISA 보호나라] - CVE-2025-29864 | 이스트소프트 알집 Mark of the Web 우회 취약점
체크포인트: 알집 압축 해제 시 웹 출처 플래그(MOTW) 누락으로 인한 악성코드 실행 위험을 방지하도록 최신 보안 버전을 배포하십시오.

[KISA 보호나라] - CVE-2025-29866 | 태그프리 제품 부적절한 권한 검증 취약점
체크포인트: 그룹웨어 및 게시판에 연동된 태그프리 웹 에디터 솔루션의 권한 우회 취약점 패치를 즉시 적용하십시오.

[KISA 보호나라] - CVE-2025-29865 태그프리 제품 파일 다운로드 취약점
체크포인트: 임의 파일 다운로드(Path Traversal) 공격을 방어하도록 웹방화벽(WAF) 룰셋을 적용하고 벤더 보안 패치를 완료하십시오.

[KISA 보호나라] - CVE-2024-23843 | 지니언스 NAC SQL Injection 취약점
체크포인트: 사내 망접근제어(NAC) 관리 서버 버전을 확인해 패치를 적용하고 관리 콘솔에 대한 비인가 접근 제어망을 재점검하십시오.

[KISA 보호나라] - CVE-2023-45801 | 나다텔 DVR 부적절한 인증 취약점
체크포인트: 영상감시 시스템(DVR)의 외부 인터넷 노출 여부를 점검하여 폐쇄망으로 분리하고 최신 펌웨어 적용 및 기본 계정 암호를 변경하십시오.

[KISA 보호나라] - CVE-2023-45800 | 한비로 그룹웨어 SQL Injection 취약점
체크포인트: 그룹웨어 웹 인터페이스 입력값 검증 로직 점검과 WAF 차단 정책을 적용하고 제조사 보안 패치를 설치하십시오.

[KISA 보호나라] - CVE-2023-45799 | 엠엘소프트 파일 다운로드 및 실행 취약점
체크포인트: 엠엘소프트 에이전트 및 관리 서버의 원격 명령 실행 취약점 패치 현황을 전수 조사하여 업데이트를 완료하십시오.
